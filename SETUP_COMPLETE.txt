   - Frontend: http://localhost:3000

   - User: user@hh3d.com / 123456

🚨 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

ISSUE 1: "Cannot GET http://localhost:3000"
─────────────────────────────────────────────
Lỗi: Frontend container không khởi động

Fix:
- Check logs: docker-compose logs frontend
- Rebuild: docker-compose down && docker-compose up --build
- Port conflict: Đổi port 3000 trong docker-compose.yml


ISSUE 2: "Cannot POST /api/login - 503 Service Unavailable"
──────────────────────────────────────────────────────────
Lỗi: Backend hoặc database không ready

Fix:
- Check database: docker-compose logs db
- Wait 30-60s cho MySQL initialize
- Check backend: docker-compose logs backend
- Verify health: curl http://localhost:5000/health


ISSUE 3: "Error: connect ECONNREFUSED 127.0.0.1:3306"
────────────────────────────────────────────────────
Lỗi: (Nếu chạy local) MySQL không chạy

Fix:
- Start MySQL service (XAMPP, Docker, hoặc CLI)
- Check .env DB_HOST = localhost (local) hoặc db (Docker)
- Verify credentials: root/root123 (mặc định)


ISSUE 4: "Port 3000 already in use"
──────────────────────────────────
Lỗi: Process khác đang sử dụng port

Fix - Windows:
  netstat -ano | findstr :3000
  taskkill /PID <PID> /F

Fix - Linux/Mac:
  lsof -i :3000
  kill -9 <PID>

Hoặc đổi port trong docker-compose.yml


ISSUE 5: "Token not found" hoặc "401 Unauthorized"
─────────────────────────────────────────────────
Lỗi: JWT token không được save

Fix:
- Check localStorage: F12 → Application → localStorage
- Verify token format: Should start with "ey..."
- Logout và login lại: Clear localStorage
